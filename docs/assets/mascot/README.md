# Poet — mascot references

Poet is rengu's mascot: a chibi anime girl who dances with a glowing scroll of light (the scroll/verse
ties to *renga*, "linked verse"). These two 1024×1024 renders are **reference art** kept so the look
isn't lost — they are the basis for producing the final Poet (done externally), not final assets.

Both were generated with the Anima checkpoint via rengu's own preview path (cosmos_predict2:
`anima_baseV10` DiT + Qwen-Image VAE + Qwen3-0.6B), 1024×1024, 20–24 steps, cfg 4, on a green
background for chroma-key extraction.

- **`poet-ref-original.png`** — the first liked take. Reference for **colors and accessories**
  (teal twin-tails + red flower ornament, navy haori with cyan ink-brush accents).
- **`poet-ref-refined.png`** — the refined-framing take. Reference for **hair style and lighting
  detail** (cleaner light ribbon / sparkles, larger framing).

The UI/favicon icon is a separate, simpler mark (a flowing cyan "Flow" wave) — see
`ui/web/public/icon.svg`.
